Leitura e Análise de Contas e Saldos com Python

Atividade prática desenvolvida durante o curso de Análise de Dados da Generation Brasil. O objetivo do exercício é importar uma base de dados em formato CSV para o Google Colab e visualizar as informações estruturadas em tabela.

## O que foi praticado

* Importação de bibliotecas: Uso da biblioteca pandas para manipulação de dados.
* Leitura de arquivos: Carregamento da base externa contas_saldos.csv utilizando o comando pd.read_csv().


## Tecnologias utilizadas

* Python
* Pandas
* Google Colab

## Estrutura do repositório

* listas_contas.ipynb: Notebook com o código desenvolvido e a tabela gerada.
* contas_saldos.csv: Base de dados original utilizada na atividade *(opcional, caso você suba o arquivo CSV junto)*.00:10
